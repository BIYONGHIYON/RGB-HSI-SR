# 실험 보고서 양식

실험 폴더의 `README.md`에 아래 8개 절을 작성합니다. 문장은 “했습니다” 체로 통일합니다. 변경 내용과 비교 기준을 먼저 쓰고 관측 이득과 한계를 구분합니다.

```markdown
# 변경한 내용이 드러나는 실험 제목

**변경 내용:** 어떤 연산·구조·손실·학습 조건을 바꿨는지 설명했습니다.

| 확인된 결과 | 상태 | 개선 여부 |
|---|---|---|
| 비교 대상과 수치 차이 | 평가 완료 / 검증 완료 / 학습 완료 / 진행 중 | 개선 / 미세 개선 / 부분 개선 / 개선 없음 / 판단 보류 / 직접 비교 불가 / 비교 기준 |

## 1. 목적과 상태
## 2. 변경한 구조와 비교 조건
## 3. 정량 결과
## 4. 기준선 대비 차이와 해석
## 5. 학습·평가 그래프
## 6. 결과 이미지
## 7. 재현 자료
## 8. 개선 여부와 다음 단계
```

조건에는 데이터, 독립 장면 수, 타일 수, 밴드, 합성 축소, 정합, 손실, seed, 학습량과 장치를 기록합니다. 기준선과 이번 수치, MSE·PSNR·SAM 차이를 같은 평가 분할에서 비교합니다. 조건이 다르면 직접 비교 불가 이유를 적습니다.

새 완료 결과는 전체 test 장면별 JSON, 학습 MSE·검증 PSNR/SAM 곡선, test 비교 그래프와 사전 고정한 5장면의 LR HSI·RGB·예측·정답 패널을 포함합니다. 검증 전용 후보에는 test 수치와 이미지를 만들지 않습니다. 없는 과거 기록은 만들지 않고 부족한 자료를 명시합니다.

재현 자료에는 실제 가중치 위치·epoch·SHA-256, 필수 설정, 정합 manifest와 결과 선택 기록을 연결합니다. 작업 브랜치, 기반 main 해시, 이관·정리·복구 이력은 보고서에 넣지 않습니다. 재현에 필요한 실제 실행 소스 해시는 JSON으로 보존합니다. 범위에는 `-`를 사용해 취소선이 생기지 않도록 합니다.
