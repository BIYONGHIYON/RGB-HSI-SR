# 원 논문 재현 · SSAI 내부 특징 차원 비교

## 목적과 조건

원 논문 기반 구조에서 내부 특징 차원 4와 6을 같은 환경에서 비교했습니다. QB·GF2는 MS 4밴드, WV3는 8밴드입니다. seed 42, 100에폭, Adam lr=1e-4, MSE, effective batch 32, micro batch 4 누적, CUDA FP32 결정론 학습을 사용했습니다. 센서별 고정 학습·검증 분할과 정규화를 유지했습니다.

2026-10-12 보관된 validation 최적 가중치를 같은 CPU FP32 코드로 평가했습니다. RR·FR은 각각 원본 H5 전체 20장입니다. 입력 정규화는 QB·WV3 2047, GF2 1023이며 예측을 clipping하지 않았습니다. PSNR은 밴드별 평균·peak 2047로 GF2에도 동일하게 적용했습니다. validation의 peak 1 PSNR 및 RGB-HSI 장면 MSE 기반 PSNR과 구분합니다.

## 차이와 판단

차이 K6-K4의 RR PSNR은 GF2 -0.095207 dB, QB -0.033705 dB, WV3 -0.029143 dB입니다. SAM은 각각 +0.011809°, +0.013501°, +0.130862°로 높아졌습니다. 잠정 QNR은 GF2 -0.000661, QB -0.001355, WV3 +0.005257로 지표별 이득이 엇갈렸습니다.

validation에서 QB·GF2는 차원 4, WV3는 차원 6의 MSE가 낮아 사전 다수결 2:1로 차원 4를 선택했습니다. test는 이 선택을 소급 변경하지 않았습니다. 단일 seed와 탐색에 사용한 test의 한계가 있으며 QNR·Q2n·SCC의 MATLAB 대응은 확인되지 않았습니다. 이 결과는 RGB-HSI 개선의 근거가 아닌 기반 구조 참고 자료입니다.
